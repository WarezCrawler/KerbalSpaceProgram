# Atmospheric Density Ratios by Altitude (KSP 1.9.1 stock)

Cell value = **local air density / 1.225 kg/m^3** (Kerbin sea-level density) - the exact number KSP feeds into an engine's `atmCurve` on that body. An altitude row gives the atmCurve x-value; scanning a column for a target ratio gives the matching altitude.

## Reading it against Kerbin

The *Kerbin* column is *italicised* (your reference). **Bold** = that body's air is **denser than Kerbin's at the same altitude** (thicker than the air you know); plain = thinner than Kerbin. The bold->plain boundary in each column is the crossover altitude. Comparison is only meaningful within Kerbin's atmosphere (0-70 km); above 70 km Kerbin is vacuum so any value is trivially 'denser'.

| Body | vs Kerbin | Crosses Kerbin density at |
|------|-----------|---------------------------|
| Jool | denser at every altitude | never (always thicker than Kerbin) |
| Eve | denser low, thinner high | ~18.5 km |
| Kerbin | reference | - |
| Duna | thinner low, denser high | ~29.4 km |
| Laythe | thinner low, denser high | ~23.4 km |

## Method (exact stock model)

From decompiled `CelestialBody.GetPressure`/`GetDensity` with real stock per-body constants:

- Pressure `P(h) = P_sl * (1 - L*h/T_sl) ^ k` (kPa), polytropic model (`atmosphereUsePressureCurve=false`), `k = gasMassLapseRate = M*g0/(R*L)`.
- Density `rho(h) = P(h)*1000 * M / (R * T(h))`, `T(h)` from the stock temperature FloatCurve; cell = `rho(h)/1.225`.  R = 8.31446.

Base altitude-temperature curve (no diurnal/latitude offset; real in-flight density varies ~a few %). Sea-level densities match stock exactly (Kerbin 1.22498, Eve 6.23837, Duna 0.14994, Laythe 0.76457 kg/m^3).

> **Notes:** Jool sea-level ratio 1.642 from its 2.2 g/mol molar mass (engine-relevant; no real surface). Laythe `gasMassLapseRate` recomputed from `M*g0/(R*L)` = 6.03 (source dataset's 0.00564 is a typo).
